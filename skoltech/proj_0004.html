📋 Аннотация

Объектом исследования работ является создание Макетных образцов для обеспечения перехода от высокого к сверхвысокому разрешению для спутниковых снимков, полученных с малых космических аппаратов (КА), типа Зоркий или аналогов, для распознавания целевых объектов на данных повышенного разрешения и для возможности визуализации геопространственных данных с привязкой к карте. Проводится анализ возможности адаптации решения повышения эквивалентного разрешения на снимках, содержащих участки снежного покрова, для обеспечения устойчивости к различным погодным условиям. Для разработки программных продуктов также проводится анализ существующих научно-технологических решений, подготовка и сбор данных для настройки и валидации алгоритмов искусственного интеллекта (ИИ). Предметом работ являются методы, модели и алгоритмы машинного обучения для генерации данных повышенного эквивалентного разрешения, распознавания объектов, и отображения геопространственных данных на картах. Целью работ является создание решений на основе ИИ для повышения качества данных, получаемых с помощью малых КА, распознавания объектов на снимках и отображения данных с географической привязкой на карте. К методам проведения работ относятся: – проведение аналитического обзора, включающего исследования публикационной активности и существующих патентов по направлениям решаемых задач – сбор и первичная обработка данных дистанционного зондирования Земли из открытых источников и у провайдеров данных отечественных КА и КА Китая; – подготовка перечня целевых типов для распознавания на спутниковых снимках; – проведение аннотации выбранных типов; – разработка программного кода и пользовательского интерфейса для визуализации данных с географической привязкой на карте; – проведение экспериментов и получение необходимых метрик качества работы алгоритмов на тестовых данных для повышения эквивалентного разрешения и распознавания объектов; – оценка и анализ полученных результатов. Результатами работ являются: – аналитический обзор по направлениям задач, решаемых в рамках проекта, и включающий обзор открытых источников по направлению и современных работ не старше 3-х лет; – патентные исследования, посвященные существующим решениям по направлению работ в России и в ключевых зарубежных странах (США, страны ЕС, Китай); – разработанный Макетный образец программного обеспечения выбора территории интереса и отображения распознанных целевых объектов на карте для целей визуализации данных с привязкой к карте; – разработанный Макетный образец модуля ПО повышения эквивалентного разрешения для обеспечения перехода от высокого к сверхвысокому разрешению, адаптированного под работу со снимками полученных с малых КА, типа Зоркий или аналогов; – разработанный Макетный образец модуля ПО распознавания целевых объектов на базе алгоритмов нейронных сетей, адаптированного под работу со снимками, полученными с малых КА, типа Зоркий или аналогов; – разработанные модели повышения разрешения в рамках подготовки Опытного образца модуля повышения эквивалентного разрешения; – подготовленный расширенный набор аннотированных данных в рамках разработки Опытного образца модуля распознавания целевых объектов. Областью применения результатов являются геоинформационные системы для распознавания объектов на спутниковых снимках. Разработки могут быть использованы в следующих направлениях: – распознавание целевых объектов на спутниковых снимках, с привязкой по координатам и отображение их на карте; – повышение эквивалентного разрешения спутниковых снимков, повышение качества спутниковых снимков, для дальнейшего использования в решении различных прикладных задач.
