📋 Описание

Программа предназначена для расчёта и оптимизации суточного графика зарядки электромобилей в пригороде, с учётом ограничения по установленной мощности подстанции, с целью: максимизироватьмощность зарядки каждого электромобиля, сгладить индивидуальные профили зарядки; учесть требования владельцев электромобилей – время отправления, конечный уровень заряда батареи. Пользователь программы задаёт следующие параметры: ограничение по установленной мощности подстанции, кВА; максимальная мощность зарядки, кВт. Пользователь предоставляет данные по электропотреблению домохозяйств за сутки и данные об электромобилях. Результат работы программы — два графика: общее потребление домохозяйств и электромобилей (кВА) без оптимизации (электромобили заряжаются на максимальной мощности) / с оптимизацией.
