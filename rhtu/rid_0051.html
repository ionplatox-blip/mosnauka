📋 Описание

Программа предназначена для расчета стационарного профиля температуры и конверсии реагентов по длине трубчатого каталитического реактора с неподвижным слоем катализатора или открытоячеистым пенокатализатором. Для структуры потоков используется модель идеального вытеснения. Программа предоставляет высокую скорость расчетов. Программа может использоваться для приближенного расчета лабораторных каталитических реакторов трубчатого типа. Функциональные возможности программы: расчет стационарного профиля температуры и конверсии, считывание параметров реактора из файла, расчет теплообмена с окружающим теплоносителем через стенку реактора при прямотоке и противотоке, запись результатов в файл. Тип ЭВМ: IBM-PC-совместимое устройство; ОС: Linux, x86_64. Язык программирования: C++ Объем программы для ЭВМ: 50,5 КБ

🔧 Способы использования

Внедрение в пакеты прикладных программ в области химической технологии, научные исследования, моделирование каталитических реакций, моделирование экспериментов в каталитических трубчатых реакторах
