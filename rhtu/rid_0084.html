📋 Описание

Программный модуль предназначен для осуществления расчета процесса биоэлектрокаталитического восстановления кислорода, протекающего на катоде биотопливного элемента (БТЭ). В основе математической модели лежит система дифференциальных уравнений в частных производных, с дробным порядком производной по времени. Программа позволяет решать систему дифференциальных уравнений конечно-разностным методом. Результатами расчета являются зависимости плотности тока (мА/см2) от напряжения ячейки (мВ), концентраций компонентов (моль/м3) от времени и по толщине активного слоя катализатора. На выходе программа выдает *.txt файлы с величинами, характеризующими данный процесс (количество итераций как по времени, так и по толщине; изменение концентраций в зависимостях от времени и толщины; значения тока во времени). Программный модуль состоит из следующих файлов: Gamma.h - заголовочный файл для объявления гамма-функций; Gamma.cpp - реализует вычисление гамма-функции; biochem.h - заголовочный файл для объявления класса, решающего систему дифференциальных уравнений, а также для объявления констант всех реакций; biochem. срр - исполняемый файл, содержит основной алгоритм программы; main.cpp. Тип ЭВМ: IBM PC-совмест. ПК; ОС: Windows. Язык программирования: С++ Объем программы для ЭВМ: 45 КБ
