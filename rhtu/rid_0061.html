📋 Описание

Программа: Программный модуль растворения лекарственных форм со сложной геометрией Авторы: Лебедев И.В., Саленко Е.Ю., Меньшутина Н.В. Назначение программы: Программа предназначена для прогнозирования высвобождения активных веществ из лекарственных форм со сложной геометрией. Область применения программы: Разработанная программа предназначена для использования в области фармацевтики для моделирования растворения при разработке новых лекарственных форм. Функциональные возможности программы: Программа позволяет моделировать процессы растворения и высвобождения с учетом природы взаимодействующих веществ, генерацию геометрии сложной лекарственной формы, включая матрицы-носители активных веществ. Тип ЭВМ: IBM PC-совместимый ПК Язык: Си# ОС: Microsoft Windows 7/8/8.1/10 Объём программы: 12 Кб.

🔧 Способы использования

Разработанная программа предназначена для использования в области фармацевтики для моделирования растворения при разработке новых лекарственных форм
