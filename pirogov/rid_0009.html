📋 Описание

Эта программа берет на вход файл формата vcf, который предварительно обрабатывает и добавляет в него информацию из базы данных dbSNP. Затем программа создает HTML-отчет с использованием PAnno и извлекает из него сведения о диплотипах. В дальнейшем программа конвертирует полученный с помощью программы HLA-exotype отчет в текстовый файл. Программа аннотирует полученные файлы (обработанный файл формата vcf; текстовые файлы, содержащие перечень диплотипов и HLA-гаплотипов) информацией из сетевого ресурса PharmGKB, объединяя их в таблицу. Затем программа разделяет таблицу по категориям Toxicity, Dosage, Metabolism_PK, Efficacy, Other и создавая отдельные таблицы по каждой из них.

🔧 Способы использования

Программа может применяться пользователями высокопроизводительных секвенаторов, использующих как короткие, так и длинные прочтения для анализа панелей генов/экзома/генома образцов при каждом запуске прибора, а также для переинтерпретации ранее полученных файлов формата vcf с учетом наличия результатов HLA-типирования.
