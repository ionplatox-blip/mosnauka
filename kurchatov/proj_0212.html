📋 Аннотация

В отчете приводится набор рекомендаций для измерения спектральных индексов, применительно к решеткам РУ ВВЭР-С. Классический метод применения набора активационных индикаторов на основе тонких фольг несмотря на высокую трудоемкость сохраняет на текущий момент приоритет перед другими методами измерения характеристик полей нейтронов. Объектом исследования являлись технологии контроля характеристик реактора. Целью данной заключительной работы по этапу являлась выработка обоснованных рекомендаций по измерению спектральных индексов в решетках РУ ВВЭР-С. В первом отчете по этапу работ на примере расчета выгорания в модельных ячейках и тестовых ТВС для реактора ВВЭР-С проанализировано изменение спектра путем расчета отношения быстрого и теплового потоков нейтронов и различных спектральных индексов. В результате выбраны спектральные индексы, которые наилучшим образом отражают изменение соотношения быстрого и теплового потоков нейтронов. Во втором отчете по этапу работ рассмотрены сравнительные расчеты спектральных индексов в модельных решетках и тестовых ТВС реакторных установок ВВЭР-C и ВВЭР. На основе расчета этих решеток и ТВС проанализировано соотношения спектральных индексов и концентраций основных делящихся материалов в процессе выгорания топлива. В третьем заключительном отчете по этапу работ рассмотрена возможность наряду с классическим методом активационных измерений с помощью тонких фольг использовать детекторы прямого заряда с эмиттерами из различных материалов как активационные индикаторы реального времени. Приведен опыт подобных измерений в прошлые годы и предложен макет родий-ванадиевого детектора нейтронов для перспективных проектов энергетических реакторов. Приведены теоретические основы токообразования детекторов прямого заряда, математические модели детекторов с различными эмиттерами, обоснована физическая достоверность результата использования математических моделей детекторов для определения соотношения активационных токов. Приводятся рекомендации по экспериментальному подтверждению расчётных исследований применительно к проекту ВВЭР-С с учётом возможностей экспериментальной стендовой базы НИЦ «Курчатовский институт». Представленные рекомендации могут иметь существенный характер при работах по определению характеристик ТВС РУ ВВЭР-С. Данный отчет является завершающим.
