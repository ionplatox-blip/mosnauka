📋 Описание

База данных (БД) предназначена для сбора, хранения и анализа информации о нуклеотидных последовательностях спейсеров , которые могут использоваться для создания направляющих РНК для Cas-эффекторов системы CRISPR-Cas VI типа, направленных против РНК карантинных фитопатогенных вирусов. БД получена анализом результатов всех представленных в базе данных NCBI virus последовательностях (дата обращения 03.07.2024) следующих вирусов растений: бенивирус некротического пожелтения жилок свеклы (Beet necrotic yellow vein virus), вирус некротической пятнистости бальзамина (Impatiens necrotic spot virus), вирус пятнистого увядания томата (Tomato spotted wilt virus), неповирус кольцевой пятнистости табака (Tobacco ringspot virus), вироид веретеновидности клубней картофеля (Potato spindle tuber viroid). БД включает ранжированный список спейсеров , нацеленных на высоко консервативные участки РНК фитопатогенов вирусной природы, созданный с использованием веб-ресурса https://casl3design.nygenome.org/.

🔧 Способы использования

База данных может представлять интерес для специалистов в области молекулярной биологии, биотехнологии, а также биоинженерии и использоваться для создания диагностических систем обнаружения карантинных фитопатогенов, основанных на системе CRISPR-Cas.
