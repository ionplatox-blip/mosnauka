📋 Описание

Программа предназначена для считывания исходных данных по моделируемому хранилищу сжиженных нефтяных газов из графического файла в формате SVG. Программа позволяет считывать из графического файла сведения как о расположении отдельных технологических объектов и их размерах, вводимых с помощью графических примитивов графического редактора, так и численные характеристики объектов, вводимые в текстовом режиме в графическое поле ввода текстового редактора. Результаты ввода передаются в таблицы, создаваемые с помощью библиотеки Pandas языка Python. Сформированные сводные таблицы данных необходимы для дальнейшего сквозного моделирования аварий на хранилищах сжиженных нефтяных газов.

🔧 Способы использования

Для расчетов последствий тяжелых аварий на объектах инфраструктуры хранения топлива в удаленных Арктических регионах
