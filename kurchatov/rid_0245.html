📋 Описание

Программа для ЭВМ позволяет осуществлять быструю реконструкцию смешивающих слоёв в слоистой архитектуре перестраиваемого оптического интерферометра без использования численной оптимизации. Программа сперва генерирует протокол измерений, специфичный для заданного интерферометра и целочисленного параметра алгоритма M. Для каждого элемента протокола измерений выполняется экспериментальное измерение передаточной матрицы интерферометра с точностью до глобальной фазы. Результаты измерений загружаются в программу, которая строит модель интерферометра. Полученная модель далее может быть использована для предсказания передаточной матрицы для произвольных значений управляющих параметров. Используемый алгоритм почти нечувствительный к ошибкам контроля фазовых слоёв вплоть до некоторого критического значения ошибки. Это критическое значение может быть увеличено за счёт выбора более маленьких значений параметра алгоритма M. Выбор маленьких M, однако, увеличивает объём измерений, поэтому на практике стоит выбирать M исходя из экспериментальной точности контроля фазовых слоёв.

🔧 Способы использования

Разработанная программа имеет существенное значение для задач оптических квантовых вычислений.
