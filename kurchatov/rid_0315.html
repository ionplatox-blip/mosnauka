📋 Описание

Программа предназначена для проведения теоретических исследований энергетики магнитных наноструктур в рамках микромагнитной модели. С использованием программы возможно нахождение путей минимальной энергии для процессов перемагничивания методом «упругой цепочки». В рамках данного метода создается цепочка реплик рассматриваемой системы, соответствующих ее разным состояниям вдоль переходной траектории. Эти реплики-состояния системы соединяются упругими пружинками, и вся цепочка натягивается между начальным и конечным минимумами энергии. Такая процедура обеспечивает прохождение цепочки реплик через седловую точку и позволяет определить путь минимальной энергии из начального состояния в конечное. На основе этих данных возможно проведение оценок активационных барьеров для различных процессов магнитного переключения.

🔧 Способы использования

Разработанная программа имеет существенное значение для задач оптических квантовых вычислений.
