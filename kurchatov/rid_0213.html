📋 Описание

Программа предназначена для управления высокоскоростной цифровой камерой с МКП затвором, автоматизированного считывания и обработки изображений поперечного профиля пучка протонов в экспериментах по протонной радиографии и изображений спектрограмм в экспериментах по диагностике потока ионов от плазмы. Программа позволяет управлять системами синхронизации камеры, регулировать уровень усиления микроканальной пластины камеры, считывать и сохранять изображения, производить онлайн математическую обработку профилей светимости по изображениям, удаленно передавать данные по протоколу TCP/IP Sockets в рамках комплексной системы автоматизации экспериментов.

🔧 Способы использования

Онлайн диагностика поперечных профилей пучков в ускорительных экспериментах с импульсными пучками, при регистрации изображений профиля пучка на сцинтилляторах. Автоматизированная, предварительная, обработка данных спектрограмм в экспериментах по диагностике плазмы.
