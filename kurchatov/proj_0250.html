📋 Аннотация

Целью работы является развитие методов построения и эффективного использования преэкзафлопсных, экзафлопсных и мультиэкзафлопсных вычислительных комплексов. Объектами исследования являются высокопроизводительные вычислительные системы, инфраструктуры на их основе, параллельный программный код. Выполнен анализ основных компонентов для создания высокопроизводительных систем, включая современные микропроцессоры, особенности параллельной файловой системы, систему планирования пользовательских заданий. Проведен анализ эффективности перспективной архитектуры векторного потокового процессора. Рассмотрены особенности использования искусственных нейронных сетей для решения численных задач. Разработаны методы планирования пользовательских заданих в системе планирования с учетом различных типов заданий и ограничений по энергопотреблению. Рассмотрены методы использования высокопроизводительных вычислений в задачах химии, материаловедения, гидродинамики и плазмодинамики. Разработана программа для ЭВМ для организации вычислений на поверхностной расчетной сетке. Разработаны методы повышения эффективности векторизации программного кода, а также распараллеливания вычислений. Предложен метод оценки эффективности использования высокопроизводительных вычислительных систем на основе комплексного подхода.
