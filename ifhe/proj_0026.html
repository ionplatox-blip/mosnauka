📋 Аннотация

В ходе выполнения проекта адаптированы и созданы несколько генеративных нейронных сетей и алгоритмов для предсказания хроматографических параметров и структурных фрагментов. Доработан предложенный ранее алгоритм ранжирования кандидатов по данным из масс-спектров электронной ионизации с применением глубокой сверточной нейронной сети. Получая на вход список структур-кандидатов, алгоритм предсказывает масс-спектры для них, затем для экспериментального масс-спектра предсказывает молекулярные отпечатки пальцев и с применением ранжирующей модели выбирает наиболее подходящие кандидаты. Для предсказания структуры молекулы из масс-спектров высокого разрешения была адаптирована модель seq2seq (последовательность-к-последовательности). Для обучения модели использовали более 100 тысяч молекул из базы данных MassBank of North America. Для прогнозирования вероятности разрыва связей в MS2-спектроскопии - графовая сверточная нейронная сеть с многослойным перцептроном. Для обучающего набора взяты 1000 экспериментальных спектров высокого разрешения из базы данных MS2 NIST 17. Предложенные “базовая” и “оптимизированная” архитектуры EI2FP для предсказания молекулярных отпечатков пальцев превосходят адаптированную из литературы модель DeepEI по точности предсказания молекулярных отпечатков пальцев. Разработана программа DeepsearchMS, которая предназначена для предсказания масс-спектров электронной ионизации низкого разрешения по SMILES вещества, а также выполняет задачу предсказания молекулярных отпечатков по экспериментальному масс-спектру. С использованием алгоритма классификации Кохонена предложен способ обнаружения пиков в ходе предобработки экспериментальных масс-спектров. Разработан алгоритм, основанный на применении кластеризации DBSCAN, критерия Хи-квадрат и линейной модели с расчётом расстояний между последовательно расположенными пиками в масс-спектре для определения их принадлежности к изотопным сериям. Для апробации разработанных подходов к ранжированию кандидатов при идентификации компонентов исследованы сложные смеси: образцы эфирных масел и пищевых масел, а также озонированной пиролизной жидкости. Применение разработанных подходов позволило в 16% случаев выбрать корректный (не противоречащий наблюдаемому индексу удерживания) кандидат из ранжированного списка (SI NIST), а в 8% случаев отнести спектр к неизвестному соединению, избежав ошибочной идентификации. Путем сопоставления хроматографических профилей по выделенным ионам удалось выбрать характеристические сигналы хроматографических пиков, которые присутствуют только в одном типе масла, что позволяет идентифицировать происхождение образца. Для этого разработан и опробован на модельных смесях основанный на методе MCR-ALS способ деконволюции и оценки вклада каждого выбранного характеристичного сигнала в условиях низкой интенсивности и наложений пиков в смеси. Для ВЭЖХ-МС данных предложен и апробирован на наборе образцов сложного состава (растительных экстрактов) алгоритм обнаружения значимых характеристичных m/z–RT сигналов, для этого применены методы машинного обучения, а именно метод опорных векторов, и две нейронные сети на основе ResNet архитектуры. Исследовано хроматографическое поведение 26 выбранных имидазолиновых и серотониновых лигандов в условиях HILIC на mixed-mode диольной и диольной неподвижной фазе. Из результатов QSRR анализа были установлены структурные свойства (молекулярные дескрипторы) соединений, оказывающие наиболее значительное влияние на их удерживание. Также было проведено квантовохимическое моделирование адсорбции изомерных диазинов на графене с использованием теории функционала плотности Кона-Шэма. Предсказанные энергии связывания и константы Генри позволяют прогнозировать хроматографическое поведение молекул только исходя их строения. Методом ВЭЖХ исследованы особенности сорбции производных пятичленных азотсодержащих гетероциклических соединений на пористом графитированном углероде – гиперкарбе. Получена корреляция значений констант Генри адсорбции производных 1,2,4-триазола, рассчитанных на основании экспериментальных данных и вычисленных молекулярно-статистическим методом. Для новых триазольных продуктов трансформации диметилгидразина рассчитаны термодинамические характеристики и молекулярные дескрипторы, значения которых можно использовать для прогнозирования времен удерживания этих соединений и их надежной идентификации. Для предсказания порядка выхода нескольких типов изомерных гетероциклических соединений были применены девять программных инструментов расчета дескрипторов в сочетании с различными алгоритмами выбора признаков (генетический (GA), Step-wise, Boruta) и четырьмя методами машинного обучения (ML). Отобраны наилучшие модели (rtest > 0,73, порядок элюирования > 60 %). Внешняя валидация подтвердила наилучшую точность модели MLR с выбором признаков GA для набора физико-химических дескрипторов, а ChemoPy/RF модель показала наилучшую точность при определении порядка выхода для критических пар.
