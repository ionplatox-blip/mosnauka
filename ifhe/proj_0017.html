📋 Аннотация

Данный проект посвящен важной проблеме — идентификации продуктов трансформации несимметричного диметилгидразина (НДМГ). Это соединение используется в качестве ракетного горючего и попадает в окружающую среду на различных этапах эксплуатации техники. Представляет опасность не только токсичность и канцерогенность самого НДМГ, но и его способность образовывать необычайно разнообразные продукты трансформации, структуры которых не установлены и мониторинг которых не проводится. Хромато-масс-спектрометрия — один из наиболее важных методов анализа сложных смесей органических веществ различного происхождения. В подавляющем большинстве случаев идентификация происходит с использованием масс-спектральных баз данных, например базы данных NIST. При этом, даже если в базе данных есть определяемое соединение, поиск может привести к неверному ответу в 10-30% случаев. Кроме того, в масс-спектральных базах данных представлено лишь ограниченное число соединений. Отсеять неверные кандидаты и повысить надежность идентификации можно с использованием информации о хроматографическом удерживании, однако обычно этой информацией пренебрегают. Современные возможности искусственного интеллекта позволяют в значительной степени решить проблему построения структуры неизвестного соединения на основе данных хромато-масс-спектрометрии. Решение этой проблемы (на примере продуктов трансформации НДМГ) и являлось основной задачей, которая рассматривалась в ходе выполнения проекта. В ходе реализации проекта создан комплексный подход к построению структуры неизвестных продуктов трансформации НДМГ, состоящий в следующем. На первом этапе в полуавтоматическом режиме для каждого соединения генерируется список структур-кандидатов, затем выполняется их ранжирование и проверка каждой из них на соответствие масс-спектральным данным (2 или 3 различных типа масс-спектрометрии) и данным о хроматографическом удерживании (не менее 2 неподвижных фаз). Ключевое значение имеет предсказание хроматографического удерживания и масс-спектров исходя из структуры молекулы, а также извлечение информации о структуре из масс-спектра с помощью технологий искусственного интеллекта. Ключевое значение для этого проекта имеют индексы удерживания (предсказанные и библиотечные). В рамках данного проекта было показано, что в базе данных NIST есть неверные записи для азотсодержащих гетероциклов, в т.ч. для известных продуктов трансформации НДМГ. Был получен надежный набор данных об индексах удерживания для ряда таких соединений и трех типов неподвижных фаз. Был разработан алгоритм поиска ошибок в химических базах данных, основанных на использовании 5 моделей машинного обучения, обученных независимо. Если для какой-то молекулы все 5 моделей дают существенно ошибочное предсказание (молекула не входила в обучающие наборы), то, скорее всего, соответствующая запись ошибочная. В рамках реализации проекта предложен подход, при котором при предсказании индексов удерживания для нестандартных неподвижных фаз строятся линейные уравнения структура-удерживание, включающие в себя индексы удерживания, предсказанные с помощью нейронных сетей для стандартных неподвижных фаз. Эти индексы удерживания использовались фактически в качестве молекулярных дескрипторов. Также созданы узкоспециальные методы для предсказания индексов удерживания для азотсодержащих соединений, таких как продукты трансформации НДМГ. Предложенный алгоритм для нецелевого хромато-масс-спектромтерического анализа был использован при исследовании продуктов трансформации НДМГ. Проведен анализ промывных вод баков, в которых хранилось горючее, анализ НДМГ, окисленного пероксидом водорода в лабораторных условиях, и анализ поверхности, содержащей продукты неполного сгорания НДМГ. С помощью возможностей искусственного интеллекта удалось предложить структуры ранее неизвестных продуктов трансформации НДМГ. В дальнейшем те структуры, для которых доступны стандартные образцы, были подтверждены с их использованием. Данный факт свидетельствует о достаточно высокой надежности разработанного подхода. Потенциальная область применимости этого метода не ограничивается продуктами трансформации НДМГ. Подход может быть применен во всех областях в которых возникает необходимость нецелевого анализа и определения структуры неизвестных органических веществ.
