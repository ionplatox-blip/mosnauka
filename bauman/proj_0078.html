📋 Аннотация

Проект направлен на создание принципиально нового технического решения: микропроцессора Леонард Эйлер и вычислительного комплекса Тераграф для обработки графов сверх-большой размерности (до одного триллиона вершин). Комплекс будет использоваться для проведения фундаментальных исследований в области биологии для моделирования белок-белковых взаимодействий на клеточном уровне и уровне клеточных сообществ, для представления графов знаний в системах предиктивной аналитики данных, в системах контроля финансовых операций. За время проведения текущего этапа были разработаны принципы построения вычислительного комплекса Тераграф, который будет состоять из трех взаимосвязанных узлов. Каждый узел состоит из хост-подсистемы, подсистемы хранения графов, подсистемы коммутации узлов, а также подсистемы обработки графов. Подсистема обработки графов представляет собой разработанный в МГТУ многоядерный микропроцессор Леонард Эйлер. Был разработан 64-х разрядный микропроцессор riscv64. Обработка ведется на основе программирования ядер обработки графов (Graph processing core), состоящих из универсального ядра riscv64im и ядра lnh64, размещенных на одном кристалле. Была разработана библиотека системного уровня для взаимодействия хост подсистемы и подсистемы обработки графов. Разработан 64-х разрядный микропроцессор ИУ6 общего назначения с набором команд riscv64. ИУ6 riscv64 и микропроцессор с набором команд дискретной математики lnh64 объединены в единое гетерогенное микропроцессорное ядро (ядро обработки графов). Реализован 24-х ядерный микропроцессор Леонард Эйлер. Реализован вычислительный комплекс Тераграф, содержащий девять микропроцессоров Леонард Эйлер и способный хранить и обрабатывать до триллиона вершин и двух триллионов ребер. На вычислительном комплексе функционирует облачная платформа Тераграф Cloud (devlab.bmstu.ru). Разработаны библиотеки системного и прикладного уровня для многопользовательского доступа к ядрам обработки графов. Поддерживаемые языки программирования: C/C++,Python. Реализовано прикладное решение и программная библиотека для формирования в памяти микропроцессора Леонард Эйлер графов знаний, их последующей обработки и визуализации.
