📋 Описание

DeepNetWork» – настольная программа с графическим интерфейсом для моделирования нейронной сети на основе генетического алгоритма выбора гиперпараметров. Программа «DeepNetWork» предназначена для прогнозирования энергопотребления с целью управления повышением энерготехнологической результативности основных производственных процессов промышленных предприятий на основе нейросетевого моделирования с генетическим алгоритмом выбора гиперпараметров. Программа обеспечивает: - оценку статистических характеристик энерготехнологических показателей основных производственных процессов; - кратко- и среднесрочный прогноз энергопотребления на основе нейросетевого моделирования с генетическим алгоритмом выбора гиперпараметров; - визуализацию прогнозных значений энергопотребления основных производственных процессов - уменьшение трудоемкости моделирования нейронной сети; - простоту и удобство применения пользователем, не владеющего знаниями машинного обучения. Тип реализующей ЭВМ: IBM РС – XP/10AT Язык программирования: Python 3 Вид и версия операционной системы: Microsoft Windows – 10 Объём программы для ЭВМ 38 кБ.
