📋 Аннотация

Объект исследования: подбор оборудования для производства получения диметилдихлорсилана, сравнение показателей метилвинилдихлорсилана с импортными аналогами, а также исследование возможности использования ASiP в качестве модификаторов силиконовых герметиков. Отчет состоит из 2-х разделов. Раздел 1 состоит из отчета по Задаче 5. Подбор оборудования для производства получения диметилдихлорсилана, Сравнение показателей метилвинилдихлорсилана с импортными аналогами. Содержит введение, основную часть, заключение, список использованных источников. Основная часть состоит из подбора оборудования для производства получения диметилдихлорсилана (приведено описание технологии; принципиальные технологические схемы; данные для расчета и выбора основного промышленного оборудования, перечень основного оборудования; характеристики и эскизные чертежи нестандартного оборудования; схемы расположения оборудования, даны рекомендации рекомендации по установке и обслуживанию реактора синтеза метилхлорсиланов), сравнения показателей метилвинилдихлорсилана с импортными аналогами (описаны технологии производства метилвинилдихлорсилана и сравниваются показатели отечественного метилвинилдихлорсилана с импортным аналогом). В заключении дана общая оценка по подбору оборудования и сравнения показателей метилвинилхлорсилановразработке технологии производства метилхлорсиланов. Раздел 2 состоит из отчета по задаче 5. Исследование возможности использования ASiP в качестве модификаторов силиконовых герметик. Содержит введение, основную часть, заключение, список использованных источников. Основная часть состоит из основных положений, синтеза исходных веществ, получения герметизирующих композиций, методов исследования, исследования герметизирующих композиций на основе полидиметилсилоксанов, модифицированных ASiP-CuCl2 с разным содержанием СКТН-А. Исследовано влияние модификатора (ASiP) на реологические, физико-механические и адгезионные свойства силоксановых герметиков. В качестве модификатора (ASiP) были использованы модификаторы на основе полиэтиленгликоля и тетраэтоксисилана, полученные с использованием в качестве катализатора хлорида меди (в количестве 0,01-0,5 масс. % от системы ПЭГ-ТЭОС) или ДЭГ-К (в количестве 0,1 масс. % от системы ПЭГ-ТЭОС), содержащие в своем составе полидиметилсилоксан СКТН марки А (в количестве 2-80 масс. % от PEOASiP). Установлено, что наиболее оптимальным по комплексу свойств является силоксановый герметик, содержащий модификатор щелочной природы ASiP-ДЭГ-К и содержащий в своем составе полидиметилсилоксан СКТН марки А в количестве 6 масс. % от PEOASiP.
