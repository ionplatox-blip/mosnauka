📋 Аннотация

Объект исследования: различные способы синтеза метилхлорсиланов, а также силоксановых полимеров на их основе. Целью работы является подготовка аналитического обзора по вопросу синтеза исходных мономеров для широкого спектра силиконов и получения силиконов на основе широкого спектра мономеров. Отчет состоит из 2-х разделов и приложения. Раздел 1 состоит из отчета по задаче 1.1. Содержит введение, основную часть, заключение, список литературы. Основная часть состоит из аналитического обзора по вопросу синтеза исходных мономеров для широкого спектра силиконов (описаны основные типы мономеров, методы получения кремнийорганических соединений, методы получения диметилдихлорсилана: одностадийный и двухстадийный синтез Гриньяра, прямой синтез, синтез метилвинилдихлорсилана) и по вопросу получения силиконов на основе широкого спектра мономеров, заключения (сравнивается получение низкомолекулярных силоксанов гидролизом мономеров, описывается получение высокомолекулярных линейных органосилоксанов, получение силоксановых каучуков). Заключение разделено на две части. В каждой части дана общая оценка по основным методам производства мономеров и силиконовых каучуков. Раздел 2 состоит из отчета по задаче 1.1. Включает введение, аналитический обзор по технологии получения устойчивых к самоконденсации органозамещенных кремнеземов ASiP, заключение, список литературы. Приложение (отчет по задаче 2) содержит результаты входного контроля и подготовки сырья, отработки условий синтеза органозамещенного кремнезема (ASiP), выходного анализа готового продукта.
