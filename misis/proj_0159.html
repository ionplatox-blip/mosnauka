📋 Аннотация

Настоящий отчет обобщает и систематизирует данные, полученные в результате исследований по этапу 3 НИР № В523004 по теме «Цифровые двойники для квантовых технологий: Управление сложными системами для задач квантовых технологий и поиска новых материалов». Целью проекта является разработка комплекса методов для исследования сложных квантовых систем, направленных на создание «цифровых двойников» квантовых приборов: точных моделей квантовых устройств, позволяющих изучить их свойства и оптимизировать их функционирование. Комплекс методов будет включать как теоретические способы изучения сложных квантовых систем, так и экспериментальную работу, направленную на создание прототипа двухкубитного фотонного вычислителя для учебных и исследовательских целей, а также демонстрацию возможности реализации квантового интернета при помощи соединения по оптической квантовой линии двух фотонных вычислителей. В ходе выполнения исследований по этапу 3 НИР была произведена разработка методов систем моделирования квантовых систем на основе тензорных сетей. Этот этап исследований оказался ключевым для понимания и анализа сложных квантовых систем. Основными достижениями данного этапа стали разработка эффективных протоколов для обмена информацией в распределенных квантовых системах и успешная апробация ранее разработанных протоколов. Это открывает новые возможности для передачи и обработки информации в сложных квантовых системах, что имеет большое значение для современной науки. Кроме того, в ходе исследований были продемонстрированы базовые принципы преобразования квантовых состояний, что дает новый взгляд на процессы в квантовой физике и открывает пути для дальнейших исследований в этой области. В целом, результаты данного этапа исследований представляют собой значительный вклад в развитие квантовой физики и открывают новые перспективы для применения полученных знаний в различных областях, требующих точного моделирования сложных квантовых систем.
