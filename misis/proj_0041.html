📋 Аннотация

Проблема создания материалов, обладающих высокой эффективностью в отношении различных патогенов, сохраняет свою высокую актуальность. Сегодня человечество сталкивается с новыми вызовами: возникновение у бактерий множественной лекарственной устойчивости, появление госпитальной грибковой инфекции, представляющей особую угрозу для пациентов с ослабленной иммунной системой, появление новых вирусов и штаммов, требующее создание высокоэффективных средств защиты органов дыхания. При реализации проекта будут использованы новые знания, полученные при реализации трехлетнего проекта, для создания новых видов биоматериалов, имеющих высокую прикладную значимость. Комплексность постановки задач исследования определяется разработкой и исследованием широкого спектра материалов, предназначенных для защиты здоровья населения, по пяти основным направлениям: (1) антибактериальные и противогрибковые покрытия для металлических имплантатов, используемых в персонализированной медицине, (2) бактерицидные нановолоконные материалы для раневых повязок и фильтры на их основе для защиты дыхания, (3) бактерицидные ткани, модифицированные наночастицами, (4) косметические средства с бустерами консервантов, а также (5) магнитные гетерогенные наночастицы с антибактериальной активностью.
