📋 Аннотация

Были разработаны: - временный технологический регламент пилотной установки получения 4,4'-диоксидифенила № ДОДФ. 223ЕП24112.00001 ПР, 4,4'-бифенол (4,4'–диоксидифенил); -ТУ 72.19.14-013-44178696-2024; -паспорт качества; -паспорт безопасности РПБ 44178696.20.92118; -лабораторный регламент на получение 4,4'-дихлордифенилсульфона ЛР 20.12.19–002–44178696–2024; -ТУ 72.19.14-014-44178696-2024 4,4'-Дихлордифенилсульфон; -паспорт качества; -паспорт безопасности РПБ 4417869.20.92228. Подана заявка №2024125152/04 (055724) 27.08.2024 на патент «СПОСОБ ПОЛУЧЕНИЯ 4,4’-ДИХЛОРДИФЕНИЛСУЛЬФОНА: МОНОМЕРА ДЛЯ ПРОИЗВОДСТВА ПОЛИФЕНИЛЕНСУЛЬФОНА». Получена лабораторная и опытная партия мономера мономера 4,4'-диоксидифенил и 4,4'-дихлордифенилсульфон для полифениленсульфона. Получены образцы СКП на основе синтезированных мономеров. Установлено, что при использовании отечественных мономеров образцы полифениленсульфона демонстрируют потемнение по сравнению с полимером, синтезированным исключительно на зарубежных мономерах (ПФСн-1). При этом комплекс физико-химических свойств полученных полимеров соответствует зарубежным аналогам. В качестве рекомендации было предложено провести дополнительную очистку (перекристаллизацию) отечественных мономеров, предоставленных Заказчиком, для улучшения качества конечного продукта. В результате проведения входного контроля мономера 4,4′-дигидроксидифенила (БФ), предоставленного Заказчиком 7 октября 2024 г. для наработки опытной партии полифениленсульфона, была проведена серия синтезов ПФСн. По результатам исследовательских испытаний термических, реологических и физико-механических свойств синтезированных образцов сделан вывод о несоответствии чистоты 4,4′-дигидроксидифенила требованиям необходимым для получения конечного продукта с комплексом физико-химических свойств, соответствующих требованиям п. 4.3 Технического задания. Даны рекомендации о необходимости дополнительной стадии очистки БФ. Заказчиком проведена перекристаллизация 4,4′-дигидроксидифенила из изопропилового спирта и воды. На основе перекристаллизованного 4,4′-дигидроксидифенила наработана опытная партия полифениленсульфона и проведены исследовательские испытания реологических, термических и физико-механических свойств опытной партии полифениленсульфона. Не смотря на улучшение в показателе цветности после дополнительной перекристаллизации 4,4′-дигидроксидифенила, цвет гранулята ПФСн, остается темнее гранул ПФСн синтезированного на основе зарубежных марок мономеров. По комплексу основных физико-химических свойств, наработанная опытная партия соответствует зарубежным аналогам. По итогу проведенных работ даны рекомендации о доработке и оптимизации стадии очистки мономеров 4,4′-дигидроксидифенила и 4,4′-дихлордифенилсульфона. Разработаны чертежи для кейджа и аппарата Иллизарова. Разработан и изготовлен опытный образец кейджа на основе отечественного СКП для межтелового спондилодеза позвоночника методом механообработки (партнер - ООО «Инстр Мед»). Разработан и изготовлен опытный образец аппарата Иллизарова на основе отечественного СКП методом литья под давлением (партнер – ООО «ПТО «Медтехника»). Разработаны 3D модели, формата STL замещающих элементов для Федерального центра нейрохирургии Разработан и изготовлен опытный образец краниимлпанта методом аддитивной печати (партнер - Федеральный центр нейрохирургии). Разработана РП ИДПО «Цифровые решения для создания 3D моделей медицинских изделий на основе СПК». Проведен Хакатона по изделиям на основе СКП. Разработаны онлайн лекции для направления 18.03.01 – «Химическая технология», по тематике синтеза мономеров для СКП, переработки СКП. Онлайн лекции для направления 12.04.04 "Биотехнические системы и технологии" , профиль «Цифровизация в здравохранении и медицинская инженерия» по теме «Разработка технологии создания объемных моделей имплантов "от КТ-снимка до модели для аддитивной печати"». Разработаны кейсы для РП по 12.04.04 направлению , профиль «Цифровизация в здравохранении и медицинская инженерия». Разработаны лабораторные практикумы для направления 18.03.01 – «Химическая технология», по тематике синтез мономеров для СКП и переработка СКП.
