📋 Описание

Изобретение относится к микробиологии, биотехнологии и медицине, а именно решает задачу получения рекомбинантного стафилолитического фермента ритафина, имеющего нуклеотидную и аминокислотную последовательность SEQ ID NO:1 и SEQ ID NO:2 соответственно, и обеспечивающего эффективное ингибирование роста культур S. aureus, S. vitulinus, S. xylosus. Технический результат заключается в создании генетической конструкции pSolSUMO-TEV-Rit SEQ ID NO:3 и получении ритафина, слитого с убиквитинподобным белком SUMO, имеющего аминокислотную последовательность SEQ ID NO:4, в гетерологической системе экспрессии E. coli, его выделении с помощью металл-хелатной хроматографии, затем обработки гибридного белка TEV-протеазой, с дальнейшим выделением и хроматографической очисткой активного ритафина с помощью металл-хелатной, а затем аффинной хроматографии на гепарин-сефарозе. Изобретение позволяет расширить арсенал ферментов, перспективных для разработки терапевтических средств против стафилококковой инфекции.

🔧 Способы использования

Изобретение относится к микробиологии, биотехнологии и медицине и может быть использовано для получения нового рекомбинантного стафилолитического фермента, названного ритафин.
