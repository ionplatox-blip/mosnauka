📋 Описание

Программа предназначена для автоматического определения значений относительных внутренних задержек сигнала радиоизлучения, регистрируемого комплексом сверхширокополосных антенн, разнесенных в пространстве. Алгоритмы программы основаны на решении оптимизационной задачи о минимизации RMS-отклонения решения локализационной задачи для калибровочного излучающего объекта в атмосфере, радиоизлучение от которого регистрируется данной системой. Программа настроена для калибровки на источнике СВЧ-излучения (1–6 ГГц) в атмосфере, регистрируемого комплексом из четырех сверхширокополосных антенн. Входными данными программы являются пространственные координаты регистрирующих антенн, пространственные координаты источника излучения – калибрующего объекта, а также серия экспериментальных данных о зарегистрированных вспышках излучения от калибрующего объекта в виде: каждая строка – отдельная вспышка излучения, номер столбца совпадает с номером антенны, в ячейках – временные моменты вспышек излучения в единицах наносекунд. Выходными данными программы являются значения относительных внутренних задержек сигналов радиоизлучения в системе антенного комплекса, выводимые на экран пользователя. Результатом применения программы является возможность численной компенсации аппаратных задержек во времени между сверхширокополосными антеннами, обусловленных недостаточной точностью калибровки кабельных трактов антенн и их пространственных координат. Программа может быть использована при решении задачи локализации источника излучения в атмосфере и позволяет повысить точность получаемого решения данной задачи за счёт корректной синхронизации временных каналов регистрации.

🔧 Способы использования

Программа позволяет: – автоматически получать значения относительных внутренних временных задержек сигнала радиоизлучения в системе из четырех сверхширокополосных антенн на основе экспериментальных данных о калибровочном источнике радиоизлучения, регистрируемого данной системой антенн, для повышения точности данных о локализации реальных исследуемых источников радиоизлучения.
