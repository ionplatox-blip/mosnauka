📋 Аннотация

Разработаны технология получения стандартных стержней из композита «сплав Б83 –Ti2NbAl и Al-Bi» для наплавки износостойких слоев с низким коэффициентом трения и порошковые проволоки для автоматизированной наплавки в горнодобывающей промышленности. Отработаны благоприятные режимы термической обработки отливок новых титановых сплавов Ti-(11-20)Nb-(1-3)Mo (ат. %) для имплантатов, которые, по сравнению с применяемыми для этой цели сплавами, не содержат вредных для человека легирующих элементов, имеют максимальную биомеханическую совместимость с костными тканями человека, лучшие коррозионную стойкость, биохимическую совместимость и высокий комплекс механических свойств. Разработана технология пропитки графита сплавами Al, позволяющая получить композит с высокой степенью пропитки и существенно более высокими эксплуатационными характеристиками по сравнению с непропитанным графитом. Отработаны благоприятные режимы плазменного распыления в среде аргона проволоки из TRIP стали ВНС9-Ш, которые обеспечивают для получение высококачественных однородных сферических гранул и сферических порошков, пригодных для ряда способов аддитивного выращивания изделий.
