📋 Аннотация

В 2024 году проводились научные исследования ряда задач геофизики, электродинамики и плазмоники. В частности, предложен алгоритм решения двумерной обратной задачи магнитотеллурического зондирования Земли для случая Е-поляризации с построением регуляризирующего функционала, включающего наряду с функционалом невязки ещё и стабилизирующий функционал. Рассмотрен метод решения задачи дифракции электромагнитного поля на неоднородной сферической частице, расположенной в верхнем полупространстве плоскослоистой среды, состоящей из двух полупространств, разделенных тонким металлическим слоем, с использованием объемных интегральных уравнений относительно электрических компонент электромагнитного поля. Разработан метод вычисления компонент электромагнитного поля через векторные потенциалы для решения задачи вычисления электромагнитного поля вертикального электрического диполя, расположенного в верхнем полупространстве плоскослоистой среды, содержащей слой графена. Методы граничных и объемных интегральных уравнений использованы для анализа плазмонного резонанса в сфероидальных частицах, расположенных в различных средах. Проведен сравнительный анализ двух методов решения задачи дифракции плоской электромагнитной волны на бесконечном плазмонном наноцилиндре кругового сечения с использованием классических и мезоскопических граничных условий. С помощью метода дискретных источников построена математическая модель дифракции на основе системы уравнений Максвелла с мезоскопическими граничными условиями, позволяющая проводить анализ плазмонных структур, состоящих из благородных и щелочных металлов.
