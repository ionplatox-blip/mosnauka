📋 Аннотация

Продолжено исследование решеток Int(A) всех замкнутых классов в частичной k-значной логике, содержащих все функции из замкнутого класса A k-значной логики и состоящих только из функций, доопределимых до некоторой функции из класса A. Для класса булевых функций S01, состоящего из всех самодвойственных функций, сохраняющих 0 и 1, доказано, что решетка Int(S01) состоит из 91 замкнутого класса. Дано описание всех 91 этих замкнутых классов. В трехзначной логике найдены импликативно неявные расширения всех 27 одноместных функций. Аналогичная задача решена для всех 27 двуместных симметрических функций, сохраняющих три константы. Рассматривается задание импликативно неявных расширений с помощью реляционных систем - систем отношений от одинакового числа аргументов. Доказано, что реляционные n-системы импликативно неявных расширений представляют собой булевы алгебры с теоретико-множественными операциями объединения, пересечения и (относительного) дополнения. В терминах булевых алгебр полностью охарактеризованы все реляционные 2-системы для импликативно неявных расширений в трехзначной логике. Продолжено исследование замкнутого класса Polpm функций, полиномиальных по модулю степени m простого числа p. Для класса Polp2 получены в явном виде отношения, описывающие этот класс. В случае произвольного простого числа p местность отношений равна четырем; для нечетного простого числа p ее можно уменьшить до трех. Для класса Polpm предложен распознающий алгоритм для функций одной переменной, заданных векторами значений, и оценена его сложность. Найдена нижняя оценка числа антицепей в декартовых степенях частично упорядоченного множества, являющегося декартовой степенью частично упорядоченного множества S(b,c), состоящего из b элементов веса 0, c элементов веса 1 и c элементов веса −1, в котором элементы одного веса несравнимы, а любой элемент, имеющий меньший вес, предшествует любому элементу, имеющему больший вес. Систематизированы некоторые результаты, связанные со счётчиковыми машинами с сумматором: уточнены определения и доказательства. Введена новая модель абстрактной машины, близкая к счётчиковым машинам с сумматором, позволяющая производить обратимые вычисления. Рассматривались полиномы Жегалкина с ограничениями степени слагаемых. При условии, что мы считаем степень константой, построен алгоритм, полиномиальный относительно длины записи полинома, для распознавания принадлежности функции классу O2.
