📋 Аннотация

В процессе выполнения научно-исследовательской темы в 2024 году были получены следующие результаты. Разработаны методы приближенного решения обратной граничной задачи для сингулярно возмущенной системы уравнений в частных производных, представляющей собой математическую модель процесса динамики сорбции, в которой процессы поглощения малы по сравнению с процессами переноса и диффузии. Изучена обратная задача для уравнения теплопроводности в случае малого коэффициента теплоемкости, в которой неизвестными являются две функции, одна из них определяет граничный режим, а другая изменение интенсивности источника во времени. Приближенные решения обратной задачи определяются, как решения системы обыкновенных дифференциальных уравнений с малым параметром при старших производных и в ряде случаев могут быть выписаны в виде формул. Для математической модели динамики сорбции с переменным кинетическим коэффициентом изучена обратная задача, состоящая в определении кинетического коэффициента по измерениям выходной концентрации вещества. Предложены и обоснованы два итерационных численных метода, дающие возможность строить приближения к точному решению в равномерной метрике. Итерационные методы программно реализованы, проведены вычислительные эксперименты с целью анализа скорости их сходимости. Получены явные аналитические представления решений нелокальных задач теплопроводности в виде рядов по полиномам Бернулли и Эйлера. Дано обоснование итерационного метода решения нелокальных задач с явным указанием на выбор весовой функции в нелокальном условии. Предложен подход на основе нейронных операторов к численному дифференцированию зашумленных данных. Подход основан на идее моделирования дифференциального оператора с помощью специального класса нейронных сетей, предназначенных для построения отображений между функциональными пространствами.
