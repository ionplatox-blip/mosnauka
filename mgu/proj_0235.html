📋 Аннотация

Основным объектом исследований являются лабораторные животные, используемые для моделирования патологий человека. Цель работы на данном этапе – разработка методов магнитной томографии и спектроскопии с целью наилучшей визуализации патологически измененных суставов, чтобы существенно повысить качество проводимой диагностики организма за счет привлечения дополнительной информации о локализации зон поражения и изменения тканевого контраста в исследуемых зонах. На слабопольном 0.5 Тл томографе были продолжены начатые на предыдущем этапе работы, касающиеся аппаратурной поддержки данного направления - визуализация недоступных для визуального обзора проводников катушек, используемых для МРТ, и получение их карт чувствительности. На высокопольном 7 Тл томографе проведена его адаптация для детектирования не только протонов (1H), но и ядер натрия (23Na). Проведены эксперименты по визуализации отдельных органов малых лабораторных животных с применением новых методик сканирования и обработки изображений. Проводились работы по оптимизации параметров импульсных последовательностей для исследования тканей с короткими временами релаксации, характерными для суставных тканей. Для исследования таких тканей проводились работы по внедрению в практику МРТ методов ретроспективного стробирования, основанные на разделении радиального k-пространства, полученного с помощью импульсных последовательностей с короткими задержками между возбуждением спиновой системы и этапами детектирования ее отклика. Степень внедрения – на методику визуализации недоступных для визуального обзора проводников катушки получен патент на изобретение, проведена апробация импульсных последовательностей на лабораторных животных (крысах) здоровых и с наличием патологий. Эффективность разработанных методов определяется возможностью гибкой адаптации аппаратных и программных средств для исследований различных органов лабораторных животных, включая суставы, с применением разных типов катушек, в том числе, и для мультиядерных приложений, что актуально для доклинических исследований с использованием лабораторных животных.
