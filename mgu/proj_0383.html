📋 Аннотация

Основные исследования велись по 4 направлениям: 1) Исследование возможностей методов построения тензорных разложений с учётом неотрицательности данных 2) Исследовались возможности применения адаптивных шагов по времени в схемах интегрирования для численного решения кинетических уравнений агрегации. 3) Приложения методов вариационного усвоения данных. 4) Применения и обоснования численных методов на основе интегральных уравнений для решения задач математической физики. Результаты за 2024 год: 1) Предложена эффективная реализация численного алгоритма на основе тензорного поезда (TT) для многокомпонентного уравнения коагуляции, с сохранением неотрицательности решения. Неестественные отрицательные элементы в построенном приближении возникают из-за ошибок малоранговой схемы разложения и дискретизации. Предложен способ применять одноранговые поправки в формате тензорного поезда, пропорциональные минимальному отрицательному элементу. Такой элемент может быть найден с помощью применения методов глобальной оптимизации, которые могут быть полностью реализованы в эффективных операциях в формате тензорного поезда. Этот прием включен в схему интегрирования по времени для многокомпонентного уравнения коагуляции, а также протестирован при постобработке стационарного решения задачи с источником частиц. 2) Получены теоретические оценки рангов степенных функций в формате квантованного тензорного поезда (QTT). Такие функции и их многочисленные обобщения (например, с экспоненциальным множителем) играют важную роль в исследованиях асимптотических решений кинетических уравнений агрегации-фрагментации. Для подтверждения построенной теории численно исследованы значения QTT-рангов этих функций с использованием процедуры TTSVD и продемонстрировано согласие между численными и аналитическими результатами. 3) Рассмотрена задача рассеяния электромагнитных волн идеальными проводниками с тонкими диэлектрическими покрытиями. Задача сводится к системе объемных и поверхностных гиперсингулярных интегральных уравнений. Решается система методом Галеркина, с использованием для поверхностного уравнения кусочно-линейных функций РВГ, а для объемного уравнения предлагается комбинированная система кусочно-линейных и кусочно-постоянных функций с призматическими носителями. Метод апробирован на модельных задачах, показавших применимость предложенного алгоритма к решению задач рассеяния. 4) Рассмотрена задача вариационного усвоения данных наблюдений с целью восстановления начального состояния и потоков тепла для математической модели термодинамики моря, разработанной в Институте вычислительной математики им. Г.И. Марчука РАН. Исследована чувствительность функционалов решения к входным данным о потоке тепла на поверхности моря в рассматриваемой задаче вариационного усвоения, а также представлены результаты численных экспериментов для модели динамики Черного моря.
