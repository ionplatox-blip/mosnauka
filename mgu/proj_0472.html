📋 Аннотация

По проведенным в рамках проекта исследованиям были получены следующие результаты в соответствии с планом работ на 2024 год: • Градиентный метод оценки оптимального масштаба гистологических изображений. • Масштабно-инвариантный метод повышения качества изображений для уменьшения ошибки анализа гистологических изображений при неточно найденном масштабе. • Метод автоматической инициализации стартовых точек для разработанной ранее обучаемой модели активных контуров для объектной сегментации желез на гистологических изображениях ЖКТ. • Доработка и оптимизация программного обеспечения PathScribe: проведены общие улучшения производительности; внедрены разработанные в проекте методы разметки полнослайдовых гистологических изображений, методы попатчевой и пиксельной сегментации изображений; реализован прототип функционала настройки и предоставления доступа к результатам разметки и применения алгоритмов сегментации между пользователями ПО; обновлён программный интерфейс реализованной библиотеки psimage. • Расширенные версии наборов полнослайдовых гистологических изображений PATH-DT-MSU WSS1, WSS2, а также TMC-IITB с полигональной разметкой для сегментации различных типов тканей и гистологических структур. • Расширенная версия набора полнослайдовых гистологических изображений соседних срезов PATH-DT-MSU WSR1 с разметкой ключевых точек для совмещения. • Полностью обучаемый метод аффинного совмещения полнослайдовых гистологических изображений. • Метод нежесткого совмещения биомедицинских изображений FNOReg, основанный на использовании нейронного оператора Фурье, обладающий свойством робастности к разрешению данных при обучении. • Проведено дополнительное тестирование методов обработки и анализа гистологических изображений, созданных индийским коллективом. Выявлен ряд особенностей по применению данных методов, обусловленных сдвигом доменной области. Несмотря на это, они могут быть применены к изображениям ЖКТ при полном переобучении моделей. Помимо решения задач, заявленных в планах на 2024 год, в рамках проекта были получены дополнительные результаты в области анализа гистологических изображений и сопутствующих задач глубокого обучения: • Метод попатчевой классификации полнослайдовых гистологических изображений с использованием графовых нейронных сетей. • Метод обнаружения размытых областей на полнослайдовых гистологических изображениях высокого разрешения с помощью многомасштабного анализа коэффициентов дискретного косинусного преобразования и оценки степени резкости границ объектов на изображении. • Метод обнаружения размытых областей на полнослайдовых гистологических изображениях высокого разрешения, основанный на использовании нейронного оператора Фурье. • Метод повышения качества изображений и подавления осцилляций Гиббса, основанный на использовании нейронных оператора Фурье. • Метод повышения качества изображений, основанный на использовании нейронной сети Колмогорова-Арнольда.
