📋 Аннотация

Получены асимптотически точные оценки функции Шеннона для площади клеточных схем из функциональных и коммутационных элементов, реализующих систему из всех самодвойственных функций. С точностью до ад-дитивной константы установлена высота клеточных схем из коммутационных элементов, связанных с вложением, имеющем нагрузку 2, полных двоичных и троичных деревьев в прямоугольные решетки минимальной длины. Получены новые уточненные асимптотические оценки сложности реализации мультиплексорной функции в классе схем из функциональных элементов в стандартном базисе. Установлено точное значение n + 2 глубины данной функции с n, n ≥ 2, адресными переменными при всех значениях n, отличных от 8 и 9. Для мультиплексорной функции алгебры логики и для дешифратора построены асимптотически оптимальные по сложности контактные схемы, которые сохраняют порядок статической и динамической активности. Получено точное значение функции Шеннона длины диагностического теста относительно прибавления по модулю 2 одной переменной к остальным переменным, а также установлена линейность по числу переменных порядка роста функции Шеннона длины проверяющего теста относительно прибавления по модулю 2 одной переменной к остальным переменным. Установлены точные значения функции Шеннона длины единичного проверяющего теста относительно произвольных константных неисправностей на выходах элементов в формулах над одним базисом жегалкинского типа. Получены новые верхние оценки функций Шеннона длин единичных тестов относительно отождествлений входов функциональных элементов. Полностью решен вопрос о существовании универсальных полиномов для классов линейных функций. Доказано отсутствие полиномов для четных k при числе переменных меньше четырех и для кратных трем k для двух переменных. Доказана универсальность произведения для классов линейных функций над полями Галуа. Предложено решение проблемы эквивалентности линейных унарных рекурсивных программ и последовательных программ для ряда семантик, основанных на уравновешенных полугруппах, порождённых операторами программ. Опубликованы результаты, касающиеся линейных унарных рекурсивных программ. Продолжены исследования возможности создания программной системы автоматизации рассуждения на основе предложенного Н.П. Брусенцовым метода анализа логических взаимосвязей. В отчётном периоде выработаны критерии оценки эффективности создаваемой системы, разработана архитектура программной системы анализа логических взаимосвязей. Также продолжены исследования вычислительных алгоритмов в симметричных системах счисления. В отчётном периоде рассмотрены некоторые операции в симметричных системах остаточных классов (ССОК).
