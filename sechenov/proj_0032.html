📋 Аннотация

Работа проводилась в рамках выполнения научно-исследовательской и опытно-конструкторской работы «Разработка программно-аппаратного комплекса трехмерной биопечати для направленного формирования тканеинженерных конструкций». Целью работы является создание передового отечественного программно-аппаратного комплекса для 3D-биопечати. В ходе работы использованы следующие методы: анализ литературы, моделирование, конструирование и др. Создание программно-аппаратного комплекса для биофабрикации, который будет позволять создавать трехмерные живые тканевые или органные конструкции. Комплекс оснащен модулями для биопечати различными гидрогелевыми композициями, а также аналитическими модулями для контроля процесса создания тканевых конструкций. Управление комплексом будет осуществляться специально разработанным программным обеспечением. Создание биопринтера позволит создавать качественные и функциональные биологические конструкции, удовлетворяющие потребности хирургического лечения.
