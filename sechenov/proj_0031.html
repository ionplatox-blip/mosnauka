📋 Аннотация

Объект исследования Нанотехнологическая система для многопараметрической трехмерной детекции биомаркеров и мониторинга их профиля в биоптатах рака молочной железы (РМЖ) на основе ориентированных конъюгатов бескадмиевых фотолюминесцентных нанокристаллов (НК) и однодоменных антител (одАТ). Цель работы: Разработка нанотехнологической системы для многопараметрической 3D-визуализации опухолевых биоптатов, позволяющей проводить комплексную характеризацию микроокружения опухоли для последующей дифференциации онкологических пациентов с целью назначения специфической иммунотерапии. Результаты: При выполнении работ на третьем заключительном этапе проекта по теме: «Нанотехнологическая система для многопараметрической трехмерной детекции биомаркеров и мониторинга их профиля в биоптатах рака молочной железы (NanoToBio)», Соглашение о предоставлении субсидии от 28.09.2021 г. № 075-15-2021-937, в соответствии с требованиями, предъявляемыми к выполняемым работам и планом работ научного исследования были выполнены следующие задачи: - Проведены дополнительные патентные исследования в соответствии с ГОСТ 15.011-96, подготовлен отчет о патентных исследованиях и база данных научных и патентных документов. - Подготовлена и подана в Федеральный институт промышленной собственности заявка на изобретение «Способ детекции онкологических маркеров в образцах опухолевой ткани и устройство для его реализации». - Проведена оценка полноты решения задачи и выполнения поставленной цели проекта. - Изготовлены лоты нанотехнологической системы для сравнительного патологоанатомического анализа, проведена оценка функциональной активности экспериментальных образцов системы; разработан лабораторный регламент изготовления нанотехнологической системы для 3D-визуализации биоптатов NanoToBio. - Проведена стандартизация условий хранения и использования нанотехнологической системы для 3D-визуализации биоптатов NanoToBio; разработана инструкция по применению нанотехнологической системы для 3D-визуализации биоптатов NanoToBio. - Выполнена оценка перспектив использования нанотехнологической системы для 3D-визуализации биоптатов NanoToBio. Иностранными партнерами осуществлена наработка рекомбинантных одАТ для получения лотов нанотехнологической системы для 3D-визуализации биоптатов NanoToBio, проведен сравнительный анализ степени выявления целевых биомаркеров, оценена чувствительность детекции и легкости интерпретации патологоанатомического исследования с использованием системы NanoToBio по сравнению с данными стандартного иммуногистохимического исследования (Брюссельский свободный университет (БСУ), Бельгия); проведен анализ параметров детекции внеклеточных белковых биомаркеров с использованием разрабатываемой нанотехнологической системы NanoToBio в сравнении со стандартным иммуногистохимическим подходом, выполнена оптимизация метода пермеабилизации для выявления внутриклеточных белковых биомаркеров с помощью разрабатываемой нанотехнологической системы для 3D-визуализации NanoToBio (Институт экспериментальной медицины им. Макса Планка (ИЭМ), Германия); а также выполнена оценка межлабораторной воспроизводимости патологоанатомического анализа клинических образцов с использованием различных лотов нанотехнологической системы NanoToBio (БСУ, Бельгия и ИЭМ, Германия). Область применения Результаты проведенных работ послужат основой для внедрения новых нанотехнологических подходов к переходу к персонализированной терапии онкологических заболеваний. Разработанная нанотехнологическая система многопараметрической 3D-визуализации опухолевых биоптатов с разрешением на уровне единичных клеток позволит проводить комплексную характеризацию микроокружения опухоли для последующей дифференциации и выбора стратегии лечения пациентов с раком молочной железы (РМЖ) — ведущей причины смертности от онкологических заболеваний среди женщин.
