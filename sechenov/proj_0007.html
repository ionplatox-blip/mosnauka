📋 Аннотация

Целью данного проекта является разработка эффективного лекарственного средства для лечения посттравматического стрессового расстройства (ПТСР) на основе компонентов растительного происхождения. В ходе его выполнения были разработаны методики количественного измерения концентрации тетрагидроканнабинола и каннабидиола в выделяемом веществе методом высокоэффективной жидкостной хроматографии c масс-селективным и ультрафиолетовым детектированием. На рабочих станциях, имеющихся в лаборатории, были выполнены расчеты молекулярных структур-кандидатов, на основе которых может быть разработан новый более эффективный препарат для лечения ПТСР. Для сгенерированных 107 молекул были проведены детализированные расчеты методом управляемой молекулярной динамики (steered MD) с использованием суперкомпьютера «Политехник ИИ» с 16 GPU NVIDIA Tesla V100. На основе полученных результатов были отобраны 9 наиболее перспективных молекул-кандидатов для проведения дополнительного анализа с использованием метода зонтичного семплирования (umbrella sampling). Далее рассматриваемые молекулы были упорядочены в порядке убывания значения функции, оценивающей перспективность их использования в качестве основы разрабатываемого лекарственного препарата, и для пяти наиболее перспективных кандидатов были разработаны схемы синтеза.
