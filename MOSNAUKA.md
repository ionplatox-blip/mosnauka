# Проект МОСНАУКА — Техническая документация

**Платформа МОСНАУКА** — это агрегатор научно-технических компетенций, B2B-портал для поиска R&D центров, учёных-экспертов и технологий в Москве. Проект объединяет базу знаний из ЕГИСУ НИОКР с AI-поиском и удобным клиентским интерфейсом.

## 📊 Масштаб проекта (Текущие данные)
- **4 344** проиндексированных записи в базе поиска.
- **22** ведущие научные организации.
- Около **3 800+** сгенерированных страниц (лаборатории, учёные, карточки организаций).
- **958** учёных-экспертов.

Структура поискового индекса (`search_index.json`):
- Проекты: 2 210
- РИД (результаты интеллектуальной деятельности): 1 388
- Учёные: 576
- Лаборатории (компетенции): 170

## 🏗 Архитектура

Проект состоит из **статичного frontend'а** (деплоится, вероятно, через Vite/GitHub Pages или отдаётся статикой) и **Python/Flask backend'а** для умного поиска.

### 1. Frontend (Статические страницы)
Веб-интерфейс построен на чистом HTML + Tailwind CSS (через CDN) + Phosphor Icons.
- **`index_v2.html` / `index-new.html`** — Главная страница платформы (Landing page).
- **`catalog.html` / `catalog_cards.html`** — Каталог R&D центров.
- **`experts.html`** — Клиентский поиск по экспертам с локальной фильтрацией (загружает `data/experts.json`).
- **`dashboard.html`** — Интерактивный личный кабинет заказчика (Канбан-доска проектов, воронка налоговых льгот ×2, чаты).
- **`tax-support.html`** — Лендинг сервиса по оформлению налоговой льготы (ст. 262 НК РФ).
- **`ai_search_results.html`** — Страница результатов глубокого гибридного поиска (AI + TF-IDF).
- **`pitch_v3.html` / `pitch_v4.html`** — Интерактивные презентации (Pitch deck) с snap-scrolling архитектурой.
- **`passport-*.html`** (21 файл, например `passport-mfti.html`) — Сводные карточки (паспорта) научных организаций.
- **Директории организаций** (`mgu/`, `mfti/`, `misis/` и др.) — Содержат тысячи сгенерированных страниц профилей лабораторий и отдельных учёных. Например, только для МГУ сгенерировано 978 страниц.

### 2. Backend (Search API)
Бэкенд-часть (`backend/app.py` и сопутствующие скрипты) реализована на **Python (Flask)** и настроена для деплоя на **Render** (`render.yaml`).
- **Движок поиска:** Гибридный (TF-IDF + Cosine Similarity по векторам эмбеддингов 512-dim).
- **Семантика:** Векторы хранятся в `embeddings.npy` и `embeddings_ids.json`.
- **LLM Интеграция:** Используется `Anthropic Claude-3-Haiku` (через OpenRouter API) для:
  1. *Query expansion* (расширение поискового запроса синонимами перед векторным поиском).
  2. *AI Re-ranking* (умная фильтрация ложных срабатываний из топ-результатов).
  3. *AI Summary* (генерация краткого делового резюме по результатам поиска).
- **API Эндпоинты:**
  - `POST /api/ai-search`: Главный эндпоинт умного поиска.
  - `GET /data/experts.json` (в `app.py`): Раздача дампа базы экспертов.

### 3. Данные (Data Pipeline)
В корне проекта и в папке `backend/` находится набор скриптов для сбора, очистки и генерации данных:
- **Синтез HTML:** `generate_site.py`, `generate_passports_v2.py` — генераторы статических страниц организаций, учёных и лабораторий на основе шаблонов.
- **Индексация:** `prepare_index.py`, `generate_embeddings.py`, `build_new_index.py` — пайплайн обработки сырых данных из ЕГИСУ НИОКР, создание `search_index.json` и генерация векторов (эмбеддингов).
- Основные массивы данных лежат в:
  - `backend/search_index.json` (полная база для RAG).
  - `public/data/experts.json` и `backend/data/experts_index.json` (база экспертов).

## 🌟 Ключевые бизнес-фичи
1. **AI-поиск по базе НИОКР:** Глубокий семантический поиск, который отличает смысл (например, "доставка грузов" в ИТ и "доставка лекарств" в биологии).
2. **База экспертов (Find an Expert):** Каталог ведущих учёных Москвы с фильтрацией по публикационной активности, компетенциям и лабораториям. Клиентский поиск реализован прямо в браузере.
3. **Навигация по льготам (НИОКР ×2):** Инструменты расчёта и методички (в `dashboard.html` и `index_v2.html`) для технологических компаний по применению ст. 262 НК РФ (списание расходов на R&D с коэффициентом до 2.0).
4. **Витрина Центров (Паспорта):** Единый, красиво свёрстанный формат вывода ключевых метрик ВУЗов и НИИ (топ проекты, оборудование, команды).
