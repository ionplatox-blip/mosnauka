Методы и методологии проведения работы Для выполнения работ по теме: Предложена теория для описания плазменно-пылевых ионизационных волн и плазменно-пылевых акустических волн, распространяющихся в плазменно-пылевом облаке микрочастиц в газовом разряде низкого давления. В модели используется гидродинамическое приближение для пылевой подсистемы пылевой плазмы в сочетании с кинетическим уравнением для ионов. Для теоретического описания поперечной неустойчивости использовано гидродинамическое описание амбиполярной диффузии плазмы, условие баланса ионизации и рекомбинации в пределах пылевого облака и уравнение движения пылевых частиц, учитывающее их инерцию, трение о газ и электрическую силу в поле амбиполярной диффузии. Развит удобный для использования новый численный метод для исследования термодинамических свойств простых атомарных жидкостей с хорошо известным потенциалом взаимодействия, а также невырожденного электронного газа на положительно заряженном однородном фоне. В рамках двумерной модели активной ланжевеновской частицы находятся аналитические уравнения, которые описывают среднюю кинетическую энергию, среднеквадратичное смещение (функцию массопереноса) и осредненную по шуму траекторию свободной активной частицы сферической формы с любым моментом инерции и вращательным коэффициентом диффузии в среде с любой динамической вязкостью. Для получения жидкостных конфигураций атомов использовался метод классической молекулярной динамики, реализованный для канонического ансамбля (NVT) с термостатом Нозе–Хувера (Nose–Hoover) и периодическими граничными условиями. Анализ дефектов в конфигурациях проводился с помощью разбиения Вороного. Расслоение квазидвумерных систем изучалось на примере монослойного плазменного кристалла в газовом разряде. Кроме того, было проведено численное исследование методом ланжевеновской динамики модельной системы в параболическом конфайнменте. Квантовый метод молекулярной динамики в рамках теории функционала плотности применяется в работе для расчета уравнения состояния, парной корреляционной функции протонов и электропроводности. Учет влияния энергии нулевых колебаний на уравнение состояния и структуру флюида водорода проводится в рамках метода молекулярной динамики на интегралах по траекториям (PIMD – path integral molecular dynamics). С применением метода классической молекулярной динамики определены диэлектрические свойства жидкостей, оказывающие влияние пассивацию электродов продуктами распада кластерных пар ионов. Моделирование диэлектрических свойств растворителей электролитов в рамках модели потенциала межатомного взаимодействия OPLS-AA. На основе разработанного метода проведен вычислительный скрининг растворителей для литий-ионных аккумуляторов. С применением методов машинного обучения проведен анализ температуры кристаллизации органических жидкостей, являющихся перспективными растворителями для литий-ионных аккумуляторов. Для исследования структурных и динамических свойств цепочечных структур пылевых частиц используется подход многомасштабного моделирования. В рамках многомасштабного подхода развиваются и используются уникальные для мировой практики методы и инструменты. Например, в рамках проекта для теоретического предсказания сил, действующих на пылевые частицы в потоке плазмы, проводится одновременное моделирование динамики пылевых частиц и плазмы с самосогласованным расчетом сил, действующих на пылевые частицы, и зарядов пылевых частиц. Самосогласованное моделирование проводится с использованием разработанного автором проекта программного пакета OpenDust, показавшим среди аналогов наилучшую производительность в задаче самосогласованного расчета сил, действующих на пылевые частицы в плазменном окружении. Моделирование с помощью метода молекулярной динамики области контакта двух несмешиваемых электролитов в состоянии термодинамического равновесия с последующим вычислением среднего электрического поля в области контакта электролитов путем решения уравнения Пуассона для усредненной концентрации заряженных компонент растворов. С помощью уравнения Ньютона проводилось математическое моделирование динамики заряженной пылевой частицы в линейной электродинамической ловушке с целью изучения дрейфового движения частицы в переменном электрическом поле ловушки. Выполнен анализ результатов экспериментальных исследований физики пылевой плазмы с использованием установки «Плазменный кристалл-3 Плюс», степень упорядоченности определялась с помощью парной корреляционной функции. Определение параметров взаимодействия пылевых частиц в плотном плазменно-пылевом облаке проводилось путем нахождения наилучшей аппроксимации экспериментально определенной ударной адиабаты сжатия плазменно-пылевого облака теоретическими данными, рассчитанными на основе модельной сильно неидеальной системы Дебая-Хюккеля. Показано, что в плотных жидкостях имеет место подобие транспортных коэффициентов по плотности замерзания. Проведены теоретические исследования по интегральному учету реакции матрицы и кумулятивного поля соседних включений в рамках теории среднего поля в приближении Онсагера. Развита теория деконволюции гистерезисов потерь на основе функций Ланжевена с памятью, с учетом 4-х независимых вкладов. Проведены молекулярно-динамические расчеты нанокомпозита, PVDF с сферическими включениями, под внешним электрическим полем, для определения пьезоэлектрических характеристик пленок. Основной экспериментальной техникой исследования оптических эффектов в плотных сильно поглощающих средах является селективное отражение. Нелинейности могут быть усилены за счет эффекта сужения диполь-дипольной ширины атомных переходов при оптическом насыщении паров. Сформулирована двухжидкостная гидродинамика для двух сортов гравитирующих частиц с притяжением между частицами одного сорта и отталкиванием между частицами разных сортов.
