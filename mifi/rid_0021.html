📋 Описание

Программа предназначена для контроля климатических параметров внутри всепогодных телекоммуникационных шкафов, а также управления различным установленным в них оборудованием с помощью системы на базе модуля RODOS-16 DIN. Исходными данными для программы являются статусные файлы, генерируемые модулем по запросу и содержащие показания датчиков, состояния релейных каналов, дискретных выходов и входов. Считываемая информация записывается в реляционную базу данных и визуализируется в виде временных рядов и графических индикаторов. Управление оборудованием осуществляется путем отправки GET-запросов по протоколу HTTP.

🔧 Способы использования

Может использоваться для мониторинга климатических условий и управления оборудованием экспериментальных установок.
