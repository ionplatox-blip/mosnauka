📋 Аннотация

Отчет представляет собой итоговые материалы третьего заключительного этапа работы научно-исследовательской лаборатории «Низкотемпературные керамические технологии (LTCC) в микроэлектронике» НИЯУ МИФИ за 2024 год. Этап посвящен отработке технологических приемов, используемых при создании компактного силовогомодуля на основе LTCC керамики. Главы отчета представлены в порядке возрастания от элементарных технологических операций по печати скрытых резиторов до создания полноценного лабораторного образца силового модуля на базе SiC MOSFET транзиторов и LTCC материалов. Отчет включает описание результатов перечисленных ниже исследований, а также результат испытания изготовленного компактного силового модуля для измерния его электрических параметров. Также отчет включает описание топологии ИМС фото-матрицы рентгеновского излучения повышенной радиационной стойкости в корпусе на базе LTCC технологии для медицинского применения, разработка котрой стартовала на предидущем этапе работы лаборатории. Резистивные пасты для печати внутренних скрытых резиторов важны для создания компактных трехмерных изделий из LTCC керамики, попутно решая задачи совместимости используемых паст с процессом пайки навесных SMD компонент. Но процесс создания толстопленочных резисторов имеет барьер в точности получения их номинального сопротивления в процессе совместного обжига, поэтому в ходе работы предложены технологические компромиссы для преодаления этого объективного физического барьера в LTCC технологии. Дизайн компактного силового модуля для применения на транспорте и зарядки аккумуляторных батарей должен включать в себя компенсированные проводниковые структуры для уменьшения возникающих в них паразитных индуктивностей. В качестве оригинального решения для уменьшения индуктивности и создаия ультро компактного дизайна силового модуля была предложена технология монтажа SiC транзиторов без использования проволочных выводов. Использование ультра компактного дизайна позволило для изготовления силового модуля применить технологию в базе котрой лежит лазерная микрообработка кадра LTCC материала для создания проводниковой топологии непосредственно на сырой керамике, без использования специализированных трафаретов изготовленных с использованием фотошаблонов. В рамках работы нимеющую высокую практическую значимость в части запуска в производство серийного рабочего изделия – ИМС фото-матрицы рентгеновского излучения повышенной радиационной стойкости в корпусе на базе LTCC технологии для медицинского применения, была выпущена конструкторско-технологическая документация (топология) для ее последующей передачи на предприятие изготовитель обладающей кремниевой технологией с нормами 90-нм. Топология успешно прошла выходной DRC тест. Спроектированный корпус ИМС будет изготовлен на базе отечественного комплекса LTCC материалов СКМ. Запуск в производство спроектированной ИМС является завершающим этапом работ, начатых в 2024 с поведенческого моделирования основных IP-блоков ИМС.
