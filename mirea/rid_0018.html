📋 Описание

Способ определения магнитных свойств ферромагнитного материала предусматривает выполнение исследований его образцов разной относительной длины λ. Для образцов цилиндрической формы с индивидуальными значениями λ, при разных значениях напряженности намагничивающего поля H (создаваемого электромагнитной системой, предпочтительно удлиненным соленоидом), экспериментально получают зависимости от λ такого из базовых магнитных параметров как магнитная индукция B в образце. Найденное семейство (при разных значениях H) зависимостей B от λ позволяет устанавливать значение λ, при котором начинается область автомодельности («плато») каждой из зависимостей B от λ полученного семейства и тем самым определять для каждой из них критериальное значение λ = [λ], при достижении и превышении которого, т.е. при λ ≥ [λ], значение индукции B в образце практически соответствует значению индукции в его материале. Согласно способу, значение [λ], при котором начинается область автомодельности каждой из зависимостей B от λ, найденных на основании экспериментов с каждым из образцов, помещаемым в исполнительную (где значения H практически постоянны) зону удлиненного соленоида, устанавливают, осуществляя аппроксимацию восходящего участка каждой из зависимостей B от λ степенной функцией, которая в избранных для нее логарифмических координатах отображает этот участок как квазилинейный. Тогда критериальное значение λ = [λ] оценивают по абсциссе точки пересечения этого участка и линейно интерполированного хвостового, отображенного в тех же координатах, относящегося к автомодельной области, участка зависимости B от λ. Для образцов из выбираемого материала получают графические и функциональные зависимости [λ] от H, а при необходимости – зависимости [λ] от установленной магнитной проницаемости материала образцов.

🔧 Способы использования

Способ относится к области магнитных измерений и может быть использован для определения магнитных свойств ферромагнитного материала, выполняя исследования по намагничиванию разных по относительной длине образ-цов из этого материала.
