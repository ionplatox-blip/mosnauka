📋 Аннотация

В отчете представлены результаты исследований 2 этапа, выполненных по заданию Минобрнауки России № FSFZ-2023-0004 от 29.06.2023 г. «Разработка принципов и подходов к созданию новых прототипов лекарственных средств и медицинских изделий» на выполнение научно-исследовательской работы в рамках государственного задания в сфере научной деятельности. Цель исследований – разработка методов получения новых аналогов хлоринов (порфиринов) и их комплексов в качестве люминесцентных биозондов для диагностики опухолей, а также путей комбинированного СВЧ и РЧ теплового воздействия при терапии опухолей, поиск новых прототипов противоопухолевых препаратов в ряду липофильных производных полиаминов, липидов и их комплексов с фармакофорными группами, или их композиций, обеспечивающих таргетную доставку лекарственного препарата в клетки мишени, соединений, позволяющих регулировать процессы окислительного метаболизма липидов, а также противовоспалительных и антимикробных препаратов. Объектом исследования являются хлорины, липиды, ароматические гетероциклические соединения, которые могут обладать комплексом биологических свойств, позволяющим использовать их и их комбинации в качестве прототипов лекарственных соединений, а также использование комбинированного СВЧ и РЧ теплового воздействия при терапии опухолей. Методология проведения работы основана на синтезе новых ранее неописанных соединений, изучение их физико-химических и биологических свойств, исследованию возможных конфигураций и конструкции установки и электрода для комбинированного нагрева. Проведены разработки по созданию и изучению свойств агентов для таргетной NIR-II биовизуализации на основе хлоринов. Синтезированы производные хлорина е6, содержащие остатки иминодиуксусной кислоты для хелатирования лантаноидов, и получены комплексы порфиринов с иттербием, для которых продемонстрированы большие времена жизни и высокие квантовые выходы инфракрасной люминесценции. Показана перспективность применения комплекса металлокомплекса иттербий-2,4-ди(-метоксиэтил)дейтеропорфирин IX для разработки чувствительных люминесцентных методов диагностики опухолей. Проведено изучение молекулярной динамики связывания энантиомеров липофильного полиамина на основе норспермина и диглицерида с децильным заместителем с одним из трансмембранных белков, участвующих в метаболизме полиаминов. Изучены альтернативные синтетические подходы и проведена оптимизации синтеза поликатионных амфифилов, которая позволила более эффективно наработать поликатионный амфифил 2Х3, используемый для доставки терапевтичеких нуклеиновых кислот. Предложена композиция нового противоопухолевого липосомального препарата, которая в виде водных дисперсий селективно может быть использована для направленной доставки противоопухолевого глицеролипида к раковым клеткам-мишеням. Для оценки ортологовой специфичности новых ингибиторов ферментных систем перекисного окисления липидов проведены работы по биосинтезу рекомбинантных форм ALOX15, ALOX15В и ALOX12 человека, и ALOX15 млекопитающих (лейкоцитарный тип 12-LOX), которые будут использованы на дальнейшем этапе проекта в качестве моделей. Показано, что наночастицы на основе PLGA (полилактид-ко-гликолид), загруженные олеатом и линолеатом тимола, могут быть использованы в качестве прототипов лекарственных соединений с антимикробной активностью. Проведены исследования по поиску новых соединений, обладающих антибактериальной активностью по отношению к ESKAPE патогенам. Проведена разработка синтеза производных разветвленного ОГМГ (олигогексаметиленгуанидин) с применением микрофлюидного аппаратного оснащения для фармацевтической разработки лекарственных форм антимикробного действия. Выполнено компьютерное моделирование возможной конструкции электрода. Проведены исследования возможных конфигураций электрода. Представлена возможная конструкция установки и электрода для комбинированного нагрева. Полученные результаты свидетельствуют о возможности создания новой системы совмещенного нагрева для лечения онкологических патологий. Научная новизна работы заключается в реализации нового способа совместного осуществления радиочастотной и микроволновой абляции с помощью одного электрода. Показано, что поры ПЭТ мембран могут выступать в качестве отдельных контейнеров для предпочтительных ЖК материалов, таким образом получая композитный полимерный материал с несколькими образцами ЖК. Полученные результаты могут быть использованы при разработке жидкокристаллических сенсоров химических и биологических примесей. Все поставленные на данном этапе работы задачи выполнены в полном объеме на высоком научном уровне. Составление научно-технического отчета проводилось в соответствии с ГОСТ 7.32-2017.
