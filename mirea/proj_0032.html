📋 Аннотация

Объектом исследования являлся лабораторный стенд для формирования протяжённого клеточного эквивалента сосуда при помощи акустических полей. Цель работы – разработка программного обеспечения для формирования протяженного клеточного эквивалента сосуда при помощи акустических полей. В рамках выполненной работы были решены задачи по разработке программного обеспечения для формирования протяжённого клеточного эквивалента сосуда с использованием акустических полей. На основании проведённых экспериментов получены данные о параметрах акустического давления в различных точках пространства, которые были использованы для обучения нейронной сети. В результате исследования получены фундаментальные данные, позволяющие значительно улучшить точность управления процессом формирования клеточного эквивалента сосуда. Эти данные также позволяют прогнозировать результаты экспериментов, что открывает возможности для дальнейшего развития технологий в области биофабрикации и тканевой инженерии. Итогом выполнения работы стало программное обеспечение, обеспечивающее управление процессом формирования клеточного эквивалента сосуда с использованием акустических полей. Проведённые исследования подтвердили эффективность предложенных методов управления акустическими излучателями и синхронизации их работы для создания стабильных акустических полей. На основании полученных результатов создается математическая модель акустического воздействия на биологические ткани, которая позволит более точно контролировать процесс биофабрикации. Полученные результаты продемонстрировали возможность точного контроля параметров акустического давления и применения этих данных для прогнозирования и автоматизации процесса биофабрикации. Разработанное ПО и созданная модель акустического воздействия могут быть использованы для дальнейших исследований и разработки новых технологий в области биофабрикации и тканевой инженерии.
