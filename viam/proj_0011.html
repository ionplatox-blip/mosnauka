📋 Аннотация

Проведено исследование микроструктуры и механических свойств образцов из тонкостенных труб стали ВНС72-Ш. Проведено исследование влияния степени деформации и температурно-временных параметров режимов деформации на структуру, механические свойства и общую коррозионную стойкость деформированного полуфабриката из металломатричного композиционного материала ВКМ40 на основе магния. Совместно с АО «НЦВ Миль и Камов» изготовлены закладные элементы для заготовок элемента тяги системы управления. Изготовлены заготовки элемента тяги системы управления методом RTM с использованием объемно-армирующей плетеной преформы из углеродного волокна Umatex и связующего ВСЭ-62 и закладных элементов АО «НЦВ Миль и Камов» для проведения дальнейших испытаний и исследований. Проведена общая квалификация (паспортизация, стадия 2) углепластика ВКУ-48/ВТкУ-5. Разработана технология изготовления методом вакуумной инфузии заготовки капота мотогондолы силовой установки вертолета на основе углепластика ВКУ-48/ВТкУ-5. Проведена общая квалификация (паспортизация, стадия 1) стеклопластиков ВПС-76, ВПС-76/Т-15(П), ВПС-76/120. Проведена отработка технологических параметров процесса склеивания и ремонта с использованием способов обработки поверхностей стеклопластиков типа КМКС-2м.120.Т10 и КМКС-4м.175.Т64 под склеивание между собой и с металлами. Проведена общая квалификация (паспортизация, стадия 1) системы пожаробезопасных ЛКП на основе грунта-наполнителя ВГ-45 и износостойкой матовой ВЭ-86 для окраски панелей приборов и элементов кабины пилота. Проведена общая квалификация (паспортизация, стадия 1) системы пожаробезопасных ЛКП на основе грунтовки ВГ-46, шпатлевки ВШ-26, декоративной эмали ВЭ-87 для защитно-декоративной окраски поверхностей интерьера. Разработаны технические условия на грунтовку электропроводящую холодной сушки ВГ-47. Разработана технология нанесения электропроводящей грунтовки для окраски деталей из ПКМ. Изготовлена опытная партия порошковой смеси КОРЦИАЛ для термодиффузионного нанесения защитного покрытия на детали из конструкционных сталей, проведены ее предварительные испытания, по результатам которых ТИ присвоена литера «О».
