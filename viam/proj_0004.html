📋 Аннотация

Разработаны технические условия на тонкостенные трубы из стали ВНС72-Ш. Проведена общая квалификация (паспортизация) тонкостенных труб из стали ВНС72-Ш (стадия 1). Разработана технология изготовления деформированных полуфабрикатов (прессованных прутков) из металломатричного композиционного материала марки ВКМ40 на основе магния. Изготовлены заготовки элемента тяги системы управления методом RTM с использованием объемно-армирующей плетеной преформы из углеродного волокна марки Umatex и связующего ВСЭ-62, исследованы физико-механические характеристики образцов, вырезанных из заготовок элемента тяги системы управления. На основании полученных результатов исследований определено, что корректировки ТР на изготовление заготовки элемента тяги системы управления не требуется. Разработана методика определения упруго-деформационных характеристик при испытании на растяжение полимерных композиционных материалов на основе объемно-армированных плетеных преформ из углеродных волокон. Проведена общая квалификация (паспортизация, стадия 3) углепластика ВКУ-48/ВТкУ-5, разработано дополнение к паспорту. Проведена общая квалификация (паспортизация, стадия 2) стеклопластиков ВПС-76, ВПС-76/Т-15(П), ВПС-76/120. Разработана технология изготовления трехслойной панели из препрегов стеклопластиков ВПС-76, ВПС-76/Т-15(П), ВПС-76/120 и сот с использованием заполнителя-сферопластика марки ВПЗ-26. Разработана технология склеивания элементов конструкций из ПКМ на основе клеевых препрегов типа КМКС-2м.120.Т10 и КМКС-4м.175.Т64 между собой и с металлами с использованием выбранных способов обработки поверхностей под склеивание. Исследовано влияние технологических параметров проведения ремонта элементов конструкций из ПКМ на основе клеевых препрегов типа КМКС-2м.120.Т10 и КМКС-4м.175.Т64 на качество поверхности заплат/накладок. Отработаны технологические режимы ремонта с учетом вида дефекта конструкции – механическое повреждение (прокол, трещины). Проведена общая квалификация (паспортизация, стадия 2) системы ЛКП на основе грунта-наполнителя ВГ-45 и износостойкой матовой ВЭ-86 для окраски панелей приборов и элементов кабины пилота. Проведена общая квалификация (паспортизация, стадия 2) системы ЛКП на основе грунтовки ВГ-46, шпатлевки ВШ-26, декоративной эмали ВЭ-87 для защитно-декоративной окраски поверхностей интерьера. Проведена общая квалификация (паспортизация) электропроводящей грунтовки холодной сушки ВГ-47 (стадия 1). Проведены сравнительные испытания механических свойств, малоцикловой усталости образцов из конструкционной стали типа Ст.45, 65Г с защитным термодиффузионным покрытием и без покрытия. Проведено исследование влияния условий хранения на качество порошковой смеси «КОРЦИАЛ», разработаны технические условия на порошковую смесь для термодиффузионного нанесения защитного покрытия на детали и крепеж из конструкционных сталей.
