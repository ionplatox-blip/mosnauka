# МОСНАУКА — Контекст проекта

## Что это
B2B-платформа для поиска R&D центров, учёных-экспертов и технологий в Москве.
Агрегирует данные из ЕГИСУ НИОКР + AI-поиск + личный кабинет заказчика.

## Масштаб
- **4 344** записи в поисковом индексе (2210 проектов, 1388 РИД, 576 учёных, 170 лабораторий)
- **22** научные организации (МГУ, МФТИ, МИСиС, Бауманка, Курчатов, РХТУ, Сколтех, МИРЭА, МИФИ, ФИАН, Сеченов и др.)
- **958** экспертов в базе
- **3 800+** сгенерированных HTML-страниц (профили учёных, лабораторий)
- **21** паспорт организации

## Стек
- **Frontend:** HTML + Tailwind CSS (CDN) + Phosphor Icons. Сборка — Vite.
- **Backend:** Python Flask, деплой на Render (`backend/render.yaml`).
- **AI:** Claude-3-Haiku через OpenRouter (query expansion, re-ranking, AI summary).
- **Поиск:** Гибридный — TF-IDF + cosine similarity по 512-dim эмбеддингам.
- **Репозиторий:** `github.com/ionplatox-blip/mosnauka`, ветка `main`.
- **Live URL:** `https://mosnauka.onrender.com`

## Бизнес-фичи
1. **AI-поиск НИОКР** — семантический + keyword, с re-ranking от Claude
2. **База экспертов** — 958 учёных, клиентский поиск в браузере
3. **Налоговая льгота ×2** — калькулятор + пошаговый гид (ст. 262 НК РФ, Перечень №988)
4. **Паспорта центров** — визуальные карточки организаций с метриками
5. **Личный кабинет** — канбан проектов, переговоры, шаблоны документов

## Деплой
- Frontend: статические файлы, отдаются Flask'ом (или Vite dev server локально)
- Backend: Render Web Service (Python), `rootDir: backend`
- Git push → автодеплой на Render (~5 мин)
