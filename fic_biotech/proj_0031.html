📋 Аннотация

Объектом исследования являются иммунохроматографические экспресс-тесты для диагностики туляремии на основе конъюгатов липополисахарида (ЛПС) возбудителя туляремии и антител к данному антигену с наночастицами с каталитической (нанозимной) активностью и сферическими наночастицами золота. Цель выполнения проекта – разработка высокочувствительных иммунохроматографических экспресс-тестов для диагностики туляремии, в которых используется каталитическое усиление оптического сигнала при нанозимной трансформации хромогенов наночастицами-маркерами, включенными в специфические иммунные комплексы микробного антигена (ЛПС Francisella tularensis) и антител к данному антигену. В ходе выполнения данных работ получены следующие основные результаты: 1. Сформирована панель металлических наночастиц для сравнительной оценки в качестве компонента экспресс-тестов для диагностики туляремии. 2. Изучено нанозимное усиление оптического сигнала, генерируемого наночастицами – маркерами в иммунохроматографических экспресс-тестах. 3. Изучены процессы формирования детектируемых иммунных комплексов и генерации оптического сигнала при проведении иммунохроматографии с нанозимным усилением для диагностики туляремии. 4. Проведена характеристика методик изготовления и контроля качества высокочувствительных иммунохроматографических экспресс-тестов для диагностики туляремии, основанных на нанозимном усилении сигнала. Проведены сравнительные лабораторные испытания экспериментальных лабораторных серий высокочувствительных и референтных иммунохроматографических экспресс-тестов для диагностики туляремии с использованием панелей положительных и отрицательных биопроб.
